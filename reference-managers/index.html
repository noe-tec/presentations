Citations

A citation shows where an idea comes from

  • It gives credit to the author
  • It lets the reader find and check the source
  • It follows a style, such as APA or IEEE
Every idea that is not yours needs a citation.
Citation types

Where the citation goes

TypeFormExample (APA 7)
ParentheticalAuthor and year in parenthesesMultilayer networks learn representations of data (LeCun et al., 2015).
NarrativeAuthor in the sentence, year in parenthesesLeCun et al. (2015) describe multilayer networks that learn representations.
  • Two authors: (LeCun & Bengio, 2015) in parentheses; "and" in narrative text
  • Three or more authors: first author plus et al.
Citation types

What you copy or rewrite

TypeFormExample (APA 7)
Direct quoteExact words, quotation marks and page"[exact words from the source]" (LeCun et al., 2015, p. [page]).
ParaphraseYour words, the same idea, still citedModels with several processing layers learn representations (LeCun et al., 2015).
SummarySeveral ideas from a section, condensedThe review presents multilayer models as learners of representations (LeCun et al., 2015).

Quotes need the page. Paraphrases and summaries need the citation too.

Academic integrity

Changing the words is not enough

Original

"Reference managers reduce the time spent on bibliographies."

Rewritten, with no citation

"Bibliography tools cut the time authors spend on reference lists."

Still plagiarism: the idea is not yours.

Checkpoint

Which sentence needs a citation?

Correct: C. It reports a result that researchers measured, so it comes from a source.

A: It is your own work, so you do not cite it.

B: It is common knowledge that any reader already has.

Reference managers

A reference manager stores your sources

  • It keeps your references in one library
  • It inserts citations and creates the bibliography for you
  • Zotero is one free example
Context

What a reference manager does

  • Stores references, PDFs and research notes in one place
  • Inserts citations while you write
  • Generates the bibliography in the style you need
  • Keeps one library that works across your documents
Why it matters

A reference you do not check is a risk

  • Readers trust your sources; a wrong one damages your credibility
  • Reviewers and editors check references one by one
  • Manual lists break when you rewrite, reorder or change styles
A reference manager stores data. Checking that data is still your job.

Word

Insert a citation from Zotero

  1. Place the cursor where the citation goes
  2. Click Add/Edit Citation in the Zotero tab
  3. Search your library and select the item
  4. Click Add/Edit Bibliography to generate the list
Citation styles

One reference, two styles

StyleReference
APALeCun, Y., Bengio, Y., & Hinton, G. (2015). Deep learning. Nature, 521(7553), 436–444. https://doi.org/10.1038/nature14539
IEEEY. LeCun, Y. Bengio, and G. Hinton, "Deep learning," Nature, vol. 521, no. 7553, pp. 436–444, 2015.

Same data in the library. Only the format changes.

Citation styles

Change the style without rewriting

  1. In the Zotero tab, click Document Preferences
  2. Choose a new style, for example APA or IEEE
  3. Click Refresh, or update the bibliography
Your text stays the same. Only the formatting changes.

Overleaf

How do you move your library into Overleaf?

  • In Zotero, select your collection and export it as a BibTeX file
  • Citation keys can change each time you export
  • We recommend installing Better BibTeX, which keeps the keys fixed

If a key changes, every \cite{} in your file breaks. The install steps are on the next slide.

Install · 5 min

Install the Better BibTeX plugin

  1. Download the latest .xpi file from the Better BibTeX releases page
  2. In Zotero, open Tools → Plugins
  3. Click the gear icon, then Install Plugin From File
  4. Select the .xpi file and click Install
  5. Restart Zotero if the Better BibTeX option does not appear
Better BibTeX releases: github.com/retorquere/zotero-better-bibtex

On a Mac, the Tools menu is at the top of the screen, not inside the Zotero window.

Hora prevista: 9:22. Actividad de 5 min, termina 9:27.
Export

Export your library as references.bib

  1. In Zotero, select the collection with your sources
  2. Right-click, then choose Export Collection
  3. Choose Better BibTeX and save the file as references.bib
  4. In Overleaf, upload it to the same folder as your main .tex file

The name must match \addbibresource{references.bib}.

Activity · 10 min

Cite your verified sources in LaTeX

  1. Replace each citation in your draft with \cite{key}
  2. Export your collection as references.bib
  3. Upload it to Overleaf and compile with Biber
  4. Check that every citation appears in the bibliography

Use \cite{key} for a parenthetical citation, such as (LeCun et al., 2015). Use \textcite{key} for a narrative citation, such as LeCun et al. (2015) describe… These are biblatex commands. In APA, both work with biblatex-apa. In IEEE, both give a number in brackets. You may see \citep and \citet in other examples; those are natbib commands and do not work with biblatex.

Checkpoint

An AI tool gives you a reference with a DOI. What should you do first?

Correct: A. A DOI must be verified against the source.

B: AI can invent DOIs, so an unchecked DOI is not evidence.

C: Changing data to fit your text is fabrication.

Why it matters today

AI makes references faster and riskier

  • Tools now write fluent text with references that look real
  • Checking a reference takes less time than a retraction
Key takeaways

Three ideas to keep

  • A reference manager organizes data; you verify it
  • Zotero connects your library to Word, LibreOffice and Overleaf
  • AI helps you search; it does not replace reading the source
