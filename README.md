# Presentations

Slide decks for teaching. Each deck lives in its own folder and is published with GitHub Pages.

## Decks

- [Reference Managers for Scientific Writing](reference-managers/): Zotero, citations (APA and IEEE), DOI and reference verification.

## Adding a deck

1. Create a folder with a short name (for example `my-topic/`).
2. Put the deck in `my-topic/index.html`, with its `css/`, `js/` and `img/` folders next to it.
3. Add a link to the list in the root `index.html`.

Each deck uses relative paths, so it works both locally and on GitHub Pages.

## Controls

- Arrow keys or space: next and previous slide.
- `S`: speaker notes (opens a separate window).
- Activity timers: click to start or pause, double-click to reset. Use − and + to adjust the time while the timer is stopped.
- `D`: dark mode.
